# Security Policy

## Reporting Security Vulnerabilities

Security is a core priority for **gtwyguard**. If you discover a security vulnerability or potential bypass in `gtwyguard`, please do **NOT** open a public issue on GitHub.

Instead, please report the vulnerability privately to the project maintainer:
- Email: **Jedidiah Roberts** (or submit via private security advisory on GitHub)

Please include:
- A description of the issue or prompt injection bypass pattern
- Steps or sample files to reproduce the behavior
- Potential impact

We will review reports promptly and publish patches accordingly. Thank you for helping keep gtwyguard secure!
