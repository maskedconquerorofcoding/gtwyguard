# Contributing to gtwyguard

Thank you for your interest in contributing to **gtwyguard**! 

## 📜 Code of Conduct
Please ensure all interactions in issues, pull requests, and discussions remain respectful, inclusive, and professional.

## 🛠️ How to Contribute

1. **Fork & Clone**
   Fork the repository on GitHub and clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/gtwyguard.git
   cd gtwyguard
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/my-new-feature
   ```

3. **Make Changes & Run Tests**
   Ensure all tests pass before submitting your PR:
   ```bash
   python -m unittest discover tests
   ```

4. **Commit & Push**
   Commit your changes with clear messages and push to your fork:
   ```bash
   git add .
   git commit -m "feat: add support for scanning XYZ file types"
   git push origin feature/my-new-feature
   ```

5. **Open a Pull Request**
   Submit a PR against the `main` branch of the official repository.
